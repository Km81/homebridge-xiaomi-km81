MiCloud 클라우드 세션 (2단계 인증)

신형 기기(예: 타워팬 p45)를 클라우드/하이브리드로 제어하려면 MiCloud 세션이 필요합니다. 2단계 인증(2FA) 계정도 여기서 한 번 로그인하면 세션이 자동 저장되고, 이후엔 재입력이 필요 없습니다. 비밀번호는 저장되지 않고 세션 토큰만 보관됩니다.

2단계 인증이 필요합니다. 아래 URL을 새 탭에서 열어 SMS/이메일로 인증코드를 받으세요.

등록된 기기 검출 (IP · 토큰 · 서버)

로그인 후, 계정에 등록된 기기들의 IP · 토큰 · 모델 · Device ID 와 각 기기가 등록된 지역(서버)을 찾아줍니다. 여러 지역을 조회하므로 수십 초 걸릴 수 있어요. 자동 등록은 하지 않습니다 — 값을 복사해 아래 장치 설정에 직접 넣으세요.
