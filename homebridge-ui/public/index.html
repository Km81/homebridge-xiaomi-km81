▸MiCloud 로그인 캐시 등록—

신형 기기(타워팬 등)를 클라우드/하이브리드로 제어하려면 MiCloud 세션이 필요합니다. 한 번 로그인하면 토큰만 저장되어 이후 자동 인증됩니다. 2단계 인증(2FA) 계정도 지원하며, 비밀번호는 저장하지 않습니다.
아래 상태는 저장된 캐시 기준이라 즉시 표시됩니다(서버 접속 불필요). 로그인/삭제 등 변경할 때만 도우미 서버에 접속합니다.

2단계 인증이 필요합니다. 아래 URL을 새 탭에서 열어 SMS/이메일로 인증코드를 받으세요.

세션은 보통 수 주~수 개월 유효하며, 만료되면 계정 로그인으로 다시 만들면 됩니다. 터미널을 선호하면 node tools/micloud-login.js 로도 만들 수 있어요(서버 불필요).

▸MiCloud 등록기기 검출IP · 토큰 · 서버 지역

계정의 모든 기기에서 IP · 토큰 · 모델 · Device ID · 등록 지역(서버)을 한 번에 찾아줍니다. 자동 등록은 하지 않으니 값을 복사해 아래 장치 설정에 직접 넣으세요. (여러 지역을 조회해 수십 초 소요)

▸자동 재로그인 (자격증명 저장)—

세션이 만료돼도 수동 로그인 없이 플러그인이 스스로 다시 로그인하도록 Mi 계정·비밀번호를 config에 저장합니다.
⚠️ 비밀번호가 Homebridge config.json에 평문 저장됩니다(설정 백업에도 포함). 감수할 때만 사용하세요.
